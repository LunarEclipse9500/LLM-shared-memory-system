- Demonstrates standard memory file structure and style conventions for this repository.
- Contains only technical, research, or architecture notes; strictly excludes personal or identifiable information.
- Formatted as concise, dense bullet points without conversational filler or narrative prose.
- File length remains strictly under ~500 words (~700 tokens) before splitting into sub-topics.
- Incremental updates append timestamped bullets (e.g. `- [YYYY-MM-DD] ...`) to preserve chronologically clear context.
