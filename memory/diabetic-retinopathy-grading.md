- The grading discussion uses a five-level DR severity scheme; referable DR is a key downstream distinction.
- DME (diabetic macular edema) is clinically important to referral decisions and should not be conflated with the DR severity grade itself.
- User has considered both Python and MATLAB implementations; Python is the more familiar environment, while MATLAB toolboxes were considered to reduce custom implementation work.
- Team familiarity matters when choosing the stack; an approach that requires the team to learn substantial MATLAB can be rejected even if technically viable.
- Prefer the least-complex implementation that can produce a defensible end-to-end prototype, then add sophistication only where it improves performance or evaluation.
